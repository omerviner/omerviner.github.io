What I did

  • Led the web app's bulk AI photo editor in a team of two developers and a designer, and made the architecture decisions. People edit one or many images with instant rendering while AI generation runs in the background.
  • Fixed 7+ second UI freezes on large photo batches by moving heavy jobs (HEIC conversion, background removal, masks) to Web Workers. The editor supports up to 1,000 images on desktop.
  • Built a history system that stores each image's actions and values instead of rendered images, with capped steps and undo recovery across multiple images.
  • Built a side-editing mode with its own UI and history, so people can experiment safely, then discard or apply. Built canvas editing tools on Fabric.js with rotation-aware geometry.
  • Split a monolithic app context into Redux Toolkit state slices, removing unnecessary UI re-renders.
  • Helped build the coded design system from Figma and Claude Design: reusable components from buttons to full screens, documented in Storybook, and the base for the design-to-code agent workflow.
  • Adapted the editor for phones: panel layouts, touch gestures and selection, and a full-screen image focus that resizes as panels open and close.

How I work with AI

  • Helped build agent workflows: a design-to-code pipeline (task bundles, agent-built, verified by tests, reviewed in separate PRs) and a per-PR translation sync that updates about 15 languages.
  • Keep code quality high with manual and AI-assisted review, regression and Playwright UI tests, and documented code design, decisions and a learning log so agents follow our standards.
